# Timelens 新界面概念稿

三套从零设计的前端界面原型，供挑选方向。每套都是一个独立的 HTML 文件，双击就能在浏览器里打开，不依赖构建工具；只有字体从 Google Fonts 加载，离线时会退回系统字体。

所有数据都是 2026-10-08 这一天的示例数据（见各文件内的 `TL` 对象），不读取真实数据库，也不和 Rust / Slint 代码相连。

| 目录 | 风格 | 时间线的核心形态 | 标志性动效 |
| --- | --- | --- | --- |
| [`solar/`](solar/index.html) | 日晷：瓷白日光、单一太阳色，自动跟随系统深浅色 | 24 小时日晷环，每段聚焦是一段弧，内圈是每 5 分钟的输入强度 | 弧线顺时针铺开；“工作时段 / 24 小时”镜头式缩放；快照用光圈从点击处展开 |
| [`darkroom/`](darkroom/index.html) | 暗房：暖黑底、安全灯琥珀色、胶片颗粒，固定深色 | 一条可拖动的胶片，每格是一张 5 分钟快照，片门所在帧投到上方银幕，旁边是场记板 | 片头倒数、银幕闪烁、场记板拍板、印样放大镜、底片显影 |
| [`blocks/`](blocks/index.html) | 积木：贴纸感粗描边、硬投影、糖果色，吉祥物“小透”，自动跟随系统深浅色 | 每小时一根积木柱，一块积木 = 5 分钟聚焦 | 积木从天而降叠成塔；小透眼睛跟着指针、会眨眼和跳；应用贴纸翻面改规则；拍立得显影 |

三套都覆盖同样的六个页面：时间线、应用（含三份排除规则）、快照、统计与报告（含键位热度）、AI 总结（含流式输出和追问）、设置；窄屏（手机宽度）下导航会移到底部，并尊重系统的“减少动态效果”设置。

## 可以试试

- 日晷：在底部时间带上拖动选一段，日晷上会出现对应扇区；点“24 小时”看整天；悬停弧线或列表行互相高亮。
- 暗房：拖动或滚轮滚动胶片来回看；`←` `→` 逐格，`I` / `O` 设入点和出点；快照页移动鼠标看放大镜，右键圈选。
- 积木：点积木看那段详情；拖时间尺；点小透；应用页点贴纸翻面；统计页点“生成本地报告”。

## 改动这些文件

每个 `index.html` 都是完整的独立文件。示例数据和快照缩略图的绘制函数在三个文件里是同一份代码；改数据时三个文件要一起改。
