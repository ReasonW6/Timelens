# Timelens CPU 优化与本机验证

2026-10-11 完成四项 CPU 优化，并更新本机核心和采集器。保留现有本地改动、界面、采集规则、拍摄频率、图片编码与画质，以及每日加密容器、单张删除、密钥销毁和空间回收路径。

- 隐藏或最小化时，UiRefresh 暂停时间线、当天历史、快照列表、报告和应用统计等界面重算。刷新请求会保留，恢复显示后补一次刷新；可见时仍使用原来的两秒刷新周期。采集、拍摄、后台任务、数据清除和必要状态检查继续运行。
- 当天统计使用最多三个范围的内存缓存。时间推进时延长持续区间；新批次按受影响应用重读，其余结果保持缓存。迟到批次、匿名输入、采集重启、合并、删除、保留期限清理、恢复、时间倒退等情况会按需要使缓存失效。当天历史保留能独立确定的已结束分段，重新计算仍可能合并的尾部，沿用原来的活动分组阈值。
- 快照调度使用带版本号的条件变量等待下一拍摄截止时间，替代每 500 毫秒读取设置。设置保存、数据变更、系统恢复及时间变化会唤醒调度器；版本号覆盖读设置到开始等待之间的竞态。原有拍摄时间槽、漏拍原因、隐私判定、图像编码和重任务互斥逻辑保留。
- 采集器按窗口事件更新相关窗口，同时刷新焦点转移的两端。进程信息缓存每次使用前验证进程创建时间，识别 PID 复用；读取失败可以重试。队列溢出和桌面切换触发全量核对，常规全量核对固定每 30 秒执行，持续窗口事件不会延后这个期限。前台切换仍立即唤醒采集循环。
