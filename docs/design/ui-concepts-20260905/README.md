## 提示词共同要求

- 单张、正视、完整的 Windows 原生桌面应用界面；输入图是布局的依据。目标画幅为 1122×752，包含约 32px 标题栏；生成输出使用近似相同比例的更大栅格，实施时回到原生窗口尺寸校准。
- 保留顶部页头、整行时间范围、左侧 330px 应用列表、中间详情、右侧功能入口及底部维护区。右侧面板在主视图中关闭。禁止增加导航栏、业务功能、装饰插画或虚构应用图标。
- 当前日期固定为 2026-09-05 星期六，上海时区。概念场景选择当天 20:00–20:30 的 30 分钟，概览为截至 20:30 的 24 小时。概览和所选范围必须区分。
- 沿用深蓝底与蓝色强调。正文约 14px、辅助文字至少 12px，标题 22px，数字对齐。使用 Segoe UI Variable / 微软雅黑风格的原生文字。
- 保留三个合成应用 WritingStudio、CodeEditor、ReadingDesk，以及 29、26、23 分钟；主应用键盘 1,044、鼠标 87。四项汇总保留打开、显示、聚焦、后台的位置。
- 补充起止时间、刻度、图例、选中状态。底部保留快照、时段报告、7/30/90 天、永久、立即清理、清空全部的顺序；30 天可见选中，清空保持危险色。
- 层级优先使用间距、对齐、字体和细分隔；避免嵌套卡片、霓虹、光晕、虚化和营销式大标题。移除页头的 PID、内部数据库名和路径等技术诊断文案。

## 三次方向要求

1. **精密刻度**：以时间刻度为视觉锚点；深墨蓝 `#0b1118`、蓝灰 `#101923`、强调蓝 `#69baff`、正文 `#edf4fa`、辅助 `#a6b6c5`。严谨的 8px 间距节奏、5–7px 圆角、细分隔，汇总数字平排，时间与选区易读。
2. **安静阅读**：以应用名称与聚焦时长为视觉锚点；灰蓝 `#111922` / `#151f29`、平静蓝 `#87bfff`、正文 `#f1f4f5`、辅助 `#afbcc7`。列表保持连续表面，指标保持平整一行，通过字重、空白和细横线组织信息。
3. **深蓝层次**：强调原生表面的精细层次；深蓝 `#08131e`、表面 `#112335` / `#162b40`、浅蓝 `#89caff`、正文 `#eef6fb`、辅助 `#b1c4d4`。8px 圆角、细边线和非常轻的表面色阶；选中应用及聚焦指标具有有控制的蓝色强调。

## 实施时必须校准

- 三张图是视觉方向，数据图形必须由真实模型计算。不得照抄生成图的条宽、热度、缺口数量或示例数值。
- 第一张右上角仍沿用了源图“选中 24 小时”，与设计场景的 30 分钟选区不一致；最终文案应区分“视野 24 小时”和“选中 30 分钟”。第一、三张的缺口状态仍有绿色示例，最终统一为语义明确的提示色。
- 原生区域尺寸按原布局校准，不能仅按生成图的像素比例缩放应用。第一张部分列表仍有独立边框，实施时按共同要求减少重复容器。
- 右侧 AI、备份、采集面板、快照、报告和危险确认的完整规则见 [审查报告](../ui-audit-20260905/audit.md)。三个方向共同修复字段标签、热图方向、选中/禁用状态及已复现的快照遮罩点击穿透。
- 自绘控件需要键盘焦点及 Enter/Space 支持；完成实现后再做原生渲染比较、键盘遍历、缩放比例和功能回归。
