# Timelens 前端重设计

## 当前要求

用户在 2026-09-05 否定了上一轮全部方案，要求改变配色和信息组织，彻底重做前端，达到可公开产品的完成度。唯一保留的空间约束是左侧侧边栏与三栏结构。旧方案“保持原区域位置、深蓝配色、只调整区域内部”的约束已被本轮指令替代。

本次三栏解释为左侧全局导航、中间工作区、右侧上下文详情。界面实现仍属于现有 Windows 原生产品；现有业务能力及数据隐私边界继续适用。

## 主工作路径

选择日期与时段 → 回看应用活动 → 选择应用或区间 → 查看详情或生成结果。

先用一张完整主屏验证视觉方向和信息层级，再将选定的系统应用到所有页面。主屏只承载当前工作，不排列全部功能入口。

## 新信息架构

| 左侧导航 | 中间工作区 | 右侧上下文 |
| --- | --- | --- |
| 时间线，默认 | 日期与范围、应用泳道、活动区间 | 所选应用/区间的时长、窗口、输入汇总、相关快照和报告入口 |
| 应用 | 应用列表及当前范围统计 | 应用身份、三份独立排除规则、合并关联；删除历史进入二级确认 |
| 快照 | 按时间排列的图片和缺失记录 | 图片预览、时间与显示器、缺失原因、删除及逐张 AI 授权 |
| 统计与报告 | 时段报告、键位统计、系统状态等二级页 | 报告覆盖与缺口、当前日期/对象的详情 |
| AI 总结 | 阅读总结和继续对话；历史、计划、提示词为二级页 | 当前范围、模型、来源图片、分支版本及任务状态 |
| 设置，侧栏底部 | 分类设置表单 | 当前操作影响、进度或必要说明 |

侧栏底部保留简短的真实记录状态和暂停/恢复入口。主要功能通过固定导航切换，不叠加多个浮动侧栏。设置分组为记录与隐私、数据与存储、AI 连接、通知与关于。

## 所有页面共同规则

- 清晰的视觉重心；一个状态只有一个主要下一步，其他动作降低强调。
- 中栏给主要内容，右栏给当前对象的上下文。长表单与高级连接参数进入相应设置，不塞进窄详情栏。
- 常规字号 14–15px，辅助文字 12–13px；导航图标、文字、数字和控件严格对齐。窄窗口与 125%/150% 缩放在实施阶段单独验收。
- 字段有持续标签、单位、当前值和必要说明。选中、焦点、禁用、忙碌、空状态、失败、暂停及记录缺口均有完整设计。
- 模态流程必须拦截背景输入并管理焦点。危险动作只出现在相关上下文和二级确认流程中。
- 记录缺口有清楚语义，键盘热图从零值低强调到高频高强调，不依靠难辨的文字或单一颜色传递信息。
- 主屏移除 PID、ProtectedSiblingPath、SQLCipher、schema、协议号及完整路径。诊断信息可在关于/诊断或对象的技术信息展开项中查看。
- 不增加效率评分、目标、项目管理、任务计划或不存在的文档/网站内容。概念图使用明确的示例活动数据，最终图表必须由真实模型驱动。

## 在线视觉研究

以下是本轮实际访问和查看的官方资料。提炼空间、层级和状态处理，不复制他人的品牌、业务内容或完整界面。

1. [Linear：A calmer interface for a product in motion](https://linear.app/now/behind-the-latest-design-refresh)，2026-03-12。参考导航退后、主要内容突出、减少分隔与色彩干扰的方式。已保存本轮页面截图及放大的侧栏比较图。
2. [Things：All-new design](https://culturedcode.com/things/features/)。参考白色阅读表面、字级、留白以及按需展开的细节。所用官方图是该功能介绍页提供的设计图，不能当作对最新版本的界面审计。
3. [Notion Calendar 桌面版](https://www.notion.com/product/calendar/download/windows)。直接查看官方三栏桌面截图，参考日历栅格、连续表面以及主区域与详情区域的宽度关系。

参考文件及来源见 [references/sources.json](references/sources.json)。上一轮 Timelens 图片不作为本次配色或空间模版；现有功能由源码和已完成的审查记录提供依据。

## 方案探索

三次独立生成，均以 1600×1000 为目标构图尺寸，包含左导航、中间主工作区和右详情，使用同一产品与示例日期。生成器实际输出均为 1586×992，保留原图，不做缩放。方向名称只用于设计文件；用户选择编号按生成结果的实际显示顺序绑定。

- 白瓷时序：浅色中性面、墨色文字和克制的玉绿色；以应用泳道和日期阅读为中心。
- 羊皮纸手记：温暖的象牙白、烟褐文字和少量陶土色；以按时间阅读活动片段为中心。
- 石墨工作台：纯石墨灰、温和白字和低饱和琥珀强调；以精密时间栅格和应用浏览为中心。

三者要比较主内容的组织与阅读方式，不只是替换同一张页面的颜色。所有参考图在送入生成前均实际打开检查。
