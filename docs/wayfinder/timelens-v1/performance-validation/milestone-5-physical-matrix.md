## 执行前准备

系统锁屏、睡眠和重启会中断用户当前桌面，需由用户选择合适时机并亲自处理解锁、登录与安全桌面。没有将实现授权解释为可以直接重启用户电脑。

使用新的隔离数据集和独立验收安装身份；不得指向用户正式数据。开始前记录本报告中的三个程序和安装包 SHA-256，设置 1 分钟快照槽，以缩短跨槽等待。AI 计划保持关闭，图像只用于本机验证。每项分别记录动作时间、槽状态、完整性结果、进程权限及退出后的残留检查。

用 `inspect_dataset` 检查明确缺口、系统区间和快照槽；需要图像判断时只在本机预览。正式报告保留状态、尺寸、字节数与资源样本，不提交实际桌面图片、凭据或真实用户数据。完成后仅清理该项创建的测试数据、安装和合成凭据。

## 收口规则

完成一项后补充执行环境、实际结果及证据链接。改变相关实现时重新执行受影响用例；单纯追加文档不重复已通过的全套回归。用户若选择延期某项，记录具体范围与原因，不将“延期”改写为“通过”。
