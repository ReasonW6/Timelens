# Timelens 里程碑 3 实现与验收报告

日期：2026-08-26

## 结论

里程碑 3 已在当前 Windows 11 宿主机开发门槛下完成。活动显示器固定槽快照、所有显示器模式、独立截图排除名单、标准缺失原因、加密预览与删除、确定性本地报告、时间/空间自动清理及重任务串行调度均已进入正式 workspace；schema 从 v8 升级为 v9。

里程碑 2 仍为完成状态。里程碑 3 没有破坏主采集闭环：最终 Release core 与 Collector 的受信握手退出码为 0；真实配对运行后，隔离 SQLCipher 数据集读取到 5 个应用、0 个监控缺口。曾出现的“等待受信采集器事件”来自未启动配对 Collector 的隔离 UI 验收实例，不是正式采集回归。

本报告不把未执行的硬件场景伪装成通过：当前宿主机只有 `DISPLAY1`，没有主动锁定用户会话、触发 UAC 安全桌面或接入第二块物理显示器。对应选择与缺失逻辑已由确定性边界测试锁定，真实锁屏、安全桌面、HDR、远程环境和物理多屏矩阵继续作为里程碑 5 的干净 Windows 11 发布验收项。

## 实现范围

- 新库默认启用每 5 分钟的当前显示器快照，可选 1、3、5、10、15、30 或 60 分钟，并可切换为所有显示器逐屏捕获。修改启用状态、间隔或目标后从修改时刻重启固定周期，不补拍失败槽。
- 活动显示器依次按聚焦窗口与显示器的最大相交面积、鼠标所在显示器、主显示器选择。跨屏不拼接；所有显示器模式为每个输出建立独立槽。
- Desktop Duplication 优先请求 `R16G16B16A16_FLOAT` 或 BGRA8，HDR/scRGB 输入在写入前映射到 SDR；图片旋转、包含指针、最长边限制为 1280，并以无附加元数据的 WebP 保存。
- 会话断开、锁屏、远程会话、非默认/不可访问输入桌面、睡眠、桌面空闲、全局暂停、独立隐私排除、低于 2 GiB 可用空间和捕获失败均只形成标准缺失槽。睡眠判断使用排除休眠时间的 Windows unbiased interrupt time。
- 截图排除名单独立于时间轴身份数据；被排除应用显示在目标屏幕时只跳过该屏，不保存触发应用名称。
- schema v9 增加快照策略、排除名单、图片 blob、固定槽、本地报告及其聚合子表。外部图片使用同一 DPAPI 用户密钥派生边界下的 AES-256-GCM 独立认证加密、随机文件名和 SHA-256 像素哈希；像素完全相同的图片去重而槽引用独立。
- 图片落盘、数据库提交、删除 tombstone 和启动对账组成可恢复文件生命周期。预览会逐张解密、校验认证标签、字节数、像素哈希和尺寸；删除保留 `user_deleted` 槽，自动清理保留 `retention_cleaned` 槽。
- 快照默认保留 7 天或 1 GiB，界面提供 1、3、7、30、90、365 天和永久选项。清理顺序为快照、持久化本地报告、活动与分钟输入明细；设置和排除规则保留，一键清空会删除图片与报告并轮换数据密钥。
- 本地报告只固化范围、生成时间、规则版本、覆盖率、应用状态时长、窗口数、输入汇总、监控缺口及快照成功/缺失统计，不复制原始分钟事件或图片。
- 快照、预览、报告、保留清理和一键清空共享进程内重任务闸门。定时槽遇到另一重任务时记录 `capture_failed`，不并发制造峰值，也不事后补拍。

## 验收结果

### 自动化回归

- `cargo fmt --all -- --check`：通过。
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`：通过，零 warning。
- `cargo test --workspace --release`：68 项通过，0 失败。
- 迁移回滚门禁已随 schema v9 修正为故意失败的 v10 迁移，确认 v9 加密备份原样恢复且失败表不存在。
- 快照测试覆盖默认策略、固定槽、跨屏选择、会话状态优先级、睡眠判定、重任务互斥、HDR 数值路径、AES-GCM、像素去重、预览、用户删除、文件对账、时间清理、1 MiB 空间上限自动清理和设置/排除保留。

### 主采集闭环

- core 作为命名管道服务端、Collector 作为客户端完成双向进程身份校验；Collector 退出码为 0，core 完成握手后退出且无残留。
- core + Collector 在隔离数据目录连续运行 15 秒，两进程均存活；停止后残留进程为 0。
- 加密库 30 分钟查询得到 5 个应用和 0 个监控缺口。`ChatGPT` 有打开、显示和聚焦时间；`WindowsTerminal`、`steamwebhelper`、`thorium`、`zen` 有打开与后台时间。

### 快照、报告与界面

- 最新调度构建在 1 分钟策略下新增两个成功槽，时间戳相差精确 60,000 ms，均为 `DISPLAY1` 的 1280×800 WebP；进程停止后无残留。
- 真实手动单帧退出码为 0，约 527.7 ms 完成，CPU 时间 0.281 秒；生成一份 232,034 字节随机名 `.tlsnap`。文件前缀为 `TLSNAP` 格式而非 `RIFF/WEBP`，数据库明文槽索引为成功。
- Slint 真实界面走查覆盖快照策略、固定槽列表、解密预览、SHA-256 完整性提示、单张删除和本地报告生成/读取。1120×720 主界面、快照弹层与报告弹层无裁切；最终保留期预设为同一行的纯文本按钮扩展并通过 Slint 编译。
- 本地报告实测可持久化并按 ID 重新加载，显示规则版本、范围、覆盖率、应用聚合、缺口及快照成功/缺失统计。
