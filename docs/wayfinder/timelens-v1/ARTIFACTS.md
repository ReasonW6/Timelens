## 未迁入 Git，可安全重新生成

- Rust `target`、独立 build/release target、WinUI `bin`/`obj`/publish、便携 .NET SDK 和下载缓存。
- IExpress 研究安装器、展开载荷、安装验证副本和测试数据库/WebP。
- 单次运行目录、重复时间轴 JSON、调试日志及失败/被替代的性能运行。
- 三个 WPR ETL。现有机器缺少 WPA/WPAExporter，无法进一步提取可靠指标；状态、大小和哈希已保留。
- 窗口校准原始 JSONL。它们可能包含本机应用路径及窗口结构，只保留匿名化结论和历史哈希。
- 性能测试的合成 30 天 SQLite、逐事件 observer JSONL 和可确定性生成的数据。

这些本机产物不是正式实现的输入。需要复核时，应使用已保留源码和脚本在目标构建或发布候选上重新生成；不要从 `.scratch/` 恢复为产品代码。
