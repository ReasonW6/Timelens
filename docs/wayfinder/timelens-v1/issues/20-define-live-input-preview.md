# 定义实时输入预览

Type: grilling
Status: resolved
Blocked by: 08

## Question

「统计」页的键盘与鼠标读数希望随输入实时变化，「键位与系统」页希望按下哪个键就让哪个键闪一下。逐键闪烁要求采集器把当前未封存分钟的逐扫描码计数每 250 ms 发给核心，相邻两次的差值能看出最近按了哪些键。这与票据 08 及[数据合同](../data-retention-privacy-contract.md)「永不持久化输入字符、按键顺序、组合键序列、原始输入事件」以及「不采集原始按键序列」的约束是什么关系？

选宝的要求：「但是我想要逐键实时闪烁，这是我上面的要求啊」；确认方案时：「好，可选护栏不加」。

## Answer

允许实时输入预览，包括逐键闪烁。那条约束防的是**记录**：不落盘，不留下可以回放的按键序列。实时预览只把当前状态显示在屏幕上，用完即丢，因此不违背它。此结论补充而不取代票据 08。

允许：

- 采集器把当前未封存分钟里已归属的输入作为 `LiveInput` 直接发给核心：键盘总数、左中右三键点击数；核心正显示「键位与系统」页时，还附带按物理位置（扫描码，不含键盘布局）计的本分钟累计数。
- 只在核心应答需要时发送：统计页显示在屏幕上时发总数，「键位与系统」页显示时才附带逐键计数；窗口隐藏、最小化或离开统计页后停止。采集器在需要时每 250 ms 醒来一次。
- 界面只保留最新一帧的逐键累计数，用上一帧与这一帧做差，让计数增加的键闪一下；较早分钟的预览只保留总数，用于在该分钟入库前补足读数。
- 键位热力图上的数字仍取自已入库的数据，随分钟封存入库更新。

不允许：

- 预览写入 spool、数据库、诊断日志或任何其他输出；预览不参与 Monitoring gap 与 Data availability record。
- 在内存中累积按键序列、逐帧增量或闪烁历史；闪烁状态只是每个键的一个翻转位，不计次数。
- 预览出现输入字符、键盘布局、组合键或按键时间。
- 为不统计输入的应用计数或闪烁：这类输入在采集器侧本来就只进匿名每日总数，预览同样不含。
- 为此增加设置开关或其他可选护栏。
