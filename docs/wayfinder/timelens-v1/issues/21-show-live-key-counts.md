# 键位热力图数字实时增加

Type: grilling
Status: resolved
Blocked by: 20

## Question

票据 20 定下「键位热力图上的数字仍取自已入库的数据，随分钟封存入库更新」「较早分钟的预览只保留总数」。实际使用中，「键位与系统」页的按键会闪，鼠标数字也随点击实时增加，键位数字却要等分钟入库、页面再隔最多 30 秒重读后才变，看起来像是没有更新。键位数字能否像鼠标数字一样实时增加？

选宝的要求：「修复键盘区域不会实时更新的问题……鼠标上的数字是正常的，也会正常增加，但是键盘区域只有闪烁，数字不增加。」

## Answer

键位热力图的数字与鼠标数字一样实时增加：已入库的每日键频加上尚未入库分钟的预览逐键计数。此结论取代票据 20 中「键位热力图上的数字仍取自已入库的数据」与「较早分钟的预览只保留总数」两条，其余条款不变。

允许：

- 「键位与系统」页显示时，界面为每个尚未入库的分钟保留其最新一次预览的逐键累计数（按扫描码，不含键盘布局），加到已入库的计数上显示；闪烁仍按票据 20 用相邻两帧做差。
- 某分钟一经入库，它的逐键计数立即丢弃，只留总数等待原有的过期处理；逐键页离开屏幕时，所有分钟的逐键计数一并丢弃。

不允许（沿用票据 20）：

- 逐键计数写入 spool、数据库、诊断日志或任何其他输出。
- 在内存中保留按键序列、逐帧增量、按键时间或闪烁历史；保留的只是每分钟、每个键的累计次数，粒度与即将入库的分钟数据相同。
