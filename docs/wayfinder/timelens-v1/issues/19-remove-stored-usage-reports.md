# 移除本地报告

Type: grilling
Status: resolved
Blocked by: 08, 18

## Question

AI 总结移除后，「统计」页的本地报告只剩聚焦总计、应用列表、键盘与鼠标、快照数量、数据覆盖和导出，其中前几项「应用」标签已实时显示，导出在数据设置里也有一份。用户很少使用它。本地报告是否还有保留价值？

## Answer

移除本地报告，不再持久化任何使用报告。此结论取代票据 08 及其[数据合同](../data-retention-privacy-contract.md)第 8 节中「本地使用报告是持久化的确定性派生工件」及其保留、空间清理顺序、应用历史删除时连带删除的条款，也取代票据 18 中「本地报告是回顾一段时间的唯一入口」一条。

- 「统计 › 应用」标签是唯一的回顾入口，按所选范围实时计算；全部记录从最早的活动记录算起。
- 数据覆盖移到「应用」标签的总览卡片：显示覆盖率、未观察时长、明确缺口与已清理段数，点开列出每一段及原因。缺失仍来自 Monitoring gap、Data availability record 与系统区间，不推测、不补齐。
- 导出 JSON / CSV 移到「应用」标签，导出当前所选范围的应用时间、输入计数、覆盖率与缺失段；数据设置中的「导出时间线当前范围」与「包含应用的本地路径」选项一并移除。
- 新迁移删除全部 `local_report*` 表；保留期与空间清理、一键清空、应用历史删除不再涉及报告。
- 快照数量与缺失原因只在快照页查看，不再在统计页汇总。
