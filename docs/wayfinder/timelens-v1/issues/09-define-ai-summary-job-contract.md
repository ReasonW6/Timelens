# 定义 AI 总结任务合同

Type: grilling
Status: resolved
Blocked by: 08

## Question

确定每日、固定间隔和手动总结的时间边界、补跑、重试、并发、版本保留、删除联动、模型与端点配置、允许发送的数据结构、用户授权和失败展示。AI 总结不得阻塞或改变确定性的本地使用报告。

## Comments

### 2026-08-23 第一轮确认

- AI 连接采用常见 BYOK 流程：选择快捷供应商或已保存的自定义供应商，填写密钥与模型并测试；通过后手动总结可直接使用，定时总结仍需分别开启。结构化文字请求不增加重复授权，更换连接配置后重新测试即可。快照授权继续逐次有效。
- 每日总结默认在本地时间 22:00 运行，范围仍为前一个完整本地自然日 00:00–24:00；允许 23 或 25 小时的夏令时日期，不总结未结束的当天。
- 固定间隔总结可完全关闭；启用时最小 1 小时，支持 1、2、3、4、6、8、12、24 小时及 1–168 小时自定义间隔。启用时建立 UTC 锚点，区间连续且不重叠；修改后从修改时刻建立新锚点，不生成旧周期残片。
- 手动总结允许任意非空时间范围并预览覆盖率及发送类别；范围内只要有任何可用数据，即使只有几分钟，也照常调用 AI。定时任务同样不设覆盖率门槛；只有完全零数据时才保存“无数据，未调用 AI”。
- 首次启用不追溯历史。恢复运行后，每种计划最多补跑最近一个完整窗口，更早窗口标记已错过；用户可手动选择旧范围。
- 全局只有一个普通权限 AI 工作进程和一个在途请求。手动任务优先但不强制中断已发送请求；计划任务等待并按计划与范围去重。AI 队列、超时或崩溃不阻塞采集、本地报告或 UI。
- 供应商配置改为 Cherry Studio 类体验：内置若干快捷供应商模板，同时允许添加、编辑并保存多个自定义提供商；用户选择供应商、填写密钥、测试并选择模型。配置变更只影响未来任务，历史总结保留当时的模型和端点主机名。

### 2026-08-23 第二轮确认

- V1 必须直接适配 Claude 与 Gemini 等原生协议，不能只依赖 OpenAI 兼容网关；快捷供应商和自定义提供商均通过明确的协议适配器工作。
- 自动重试默认开启且默认 3 次，但是否重试和重试次数由用户配置。认证、权限、模型或格式错误仍直接失败；限流遵循服务端等待提示，网络、超时和服务器错误按用户配置退避重试。
- AI 总结改为流式对话侧栏：展示任务进度、提供商实际返回的公开推理内容或摘要、流式输出和最终结果；供应商未返回的隐藏思维链不得伪造。侧栏底部允许用户继续提问。
- 不使用固定 3 分钟或 10 分钟总时限。连接失败立即展示；流式请求只受连接超时和可配置的无响应超时约束，只要持续收到内容即可继续，用户始终可以取消。
- 提供商报错直接在对话侧栏显示原始状态和错误正文，但必须先遮蔽 API 密钥、Authorization、秘密请求头和其他凭据；错误不得进入诊断日志的内容字段。
- 系统提示词必须约束输出格式、范围和要求，同时预留用户可编辑、可保存和恢复默认值的提示词配置。不可编辑的数据白名单与隐私过滤在提示词之外强制执行，用户提示词不能扩大允许发送的数据。
- 模型列表展示能力标识，至少以小眼睛标出视觉能力。无视觉能力模型只能进行纯文本总结；视觉模型可由用户选择纯文本或在手动总结中逐张授权图片。
- 同一范围每次成功重新生成形成新版本，默认保留最近 3 个成功版本，固定版本不自动删除；失败重试不产生空版本。全部版本仍受 AI 时间与空间清理策略约束。
- 长范围数据包含覆盖率、系统状态、全部应用聚合、按小时趋势、输入总数与前 20 个高频键位；超出上下文时按自然日分块再汇总，开始前展示预计请求次数，禁止静默丢弃应用。

### 2026-08-23 第三轮确认

- 内置快捷配置覆盖 OpenAI、Anthropic Claude、Google Gemini、Azure OpenAI、OpenRouter、DeepSeek、硅基流动和 Moonshot/Kimi；自定义提供商可选择 OpenAI 兼容、Anthropic 兼容或 Gemini 兼容协议并保存多个配置。
- 模型能力优先使用提供商元数据，再叠加内置目录；无法确定时显示“能力未知”，允许用户对当前提供商手动覆盖视觉、公开推理及工具能力。视觉能力以小眼睛标识。
- 本地加密保存用户问题、AI 回答、提供商公开返回的推理内容、脱敏错误和时间，与对应总结共同备份、清理和删除；不保存隐藏推理、请求头或完整网络报文，允许单独清空对话。
- 快照不会因出现在既有对话中而获得后续请求授权；追问需要模型再次查看图片时，用户必须重新选择并授权本次发送。
- 提示词分为不可编辑的数据过滤与安全边界、可编辑的全局默认系统提示词、以及可为手动、每日或间隔任务选择的命名提示词预设；提供只读变量并支持恢复官方默认值。
- 只有尚未收到任何正文的失败请求才自动重试；流式输出开始后断线保留部分内容和错误，由用户主动重新生成并形成新版本。
- 每个成功总结版本拥有独立对话分支；从任意版本继续提问只进入该分支，不把旧分支消息自动拼入新版本。
- AI 总结、版本和对话默认保留 30 天或 100 MB，从最旧未固定版本开始自动清理。固定版本不按时间删除；达到空间上限时要求用户处理，不静默删除固定版本。
- 成功通知默认关闭，失败通知默认开启，均可设置。通知打开对应对话侧栏；已错过和无数据只进入任务历史。
- 追问上下文行为按[Cherry Studio 官方源码核验](../research/cherry-studio-context-behavior.md)对齐：本地加密消息以父节点形成分支树，每次只发送当前分支，不依赖提供商会话 ID；支持清除上下文、最近 N 条限制，并默认在约 80% 可用窗口时把较早内容持久化压缩、保留约 30% 近期原文，原始本地消息不删除。正常重新生成创建兄弟分支，失败且无有效回答的重试原位复用节点。
- 为在源活动被清理后继续追问，首次总结的隐私过滤结构化数据包作为隐藏 AI 上下文快照本地加密保存并与总结共同清理；它不含系统提示词、凭据、请求头或完整网络请求。后续发送以本地当前分支为准。

### 2026-08-23 最终确认

- 每个每日计划、固定间隔计划和手动总结都可以选择已保存供应商、具体模型与提示词预设。任务保存无密钥配置快照；配置修改只影响未来，配置或模型删除会暂停相关计划并要求重新选择。
- 自动重试在供应商配置中默认开启 3 次、可设为 0–10 次或关闭；计划可覆盖该值。手动任务使用供应商默认，且只有未收到正文时自动重试。
- 官方系统提示词可完整编辑、另存和恢复默认；每个总结版本加密保存实际提示词快照。数据白名单、图片授权和密钥保护由代码强制，不依赖提示词。
- 提供商适配器只展示模型实际支持的类型化高级参数，不发送未知参数，也不开放原始 JSON 注入。
- 对话侧栏显示提供商返回的输入、输出、缓存及推理 Token；只有提供商明确返回费用时才显示金额，不使用本地价格猜算。
- 上下文压缩计入请求数与 Token。压缩失败时保留消息树，退回模型能容纳的最近完整用户对话并明确提示被省略范围。
- 协议支持时关闭提供商服务端存储，且普通聊天永不依赖服务端会话续接；配置页提示请求仍受提供商自身的数据政策约束。

## Answer

每日、固定间隔和手动 AI 总结的时间边界、供应商及模型选择、调度补跑、单请求并发、重试、流式对话、提示词、上下文压缩、快照能力、版本保留、通知、删除联动和失败展示均已确定，详见[AI 总结任务合同](../ai-summary-job-contract.md)。

V1 采用多提供商 BYOK 体验，直接适配 OpenAI、Anthropic Claude 与 Google Gemini 协议族并提供常见供应商快捷配置。每个计划与手动请求可自行选择供应商、具体模型和提示词；任务保存无密钥配置快照。初始总结与追问统一使用本地加密消息树和隐私过滤上下文快照，行为依据[Cherry Studio 普通聊天官方源码核验](../research/cherry-studio-context-behavior.md)，不依赖供应商保存会话，也不展示或伪造未公开的隐藏思维链。
