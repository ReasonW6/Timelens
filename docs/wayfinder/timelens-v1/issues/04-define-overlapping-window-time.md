# 定义重叠窗口的前台与后台时间

Type: grilling
Status: resolved
Blocked by: 01

## Question

精确定义 Timelens 的“打开”“前台”“后台”“可见”“获得焦点”与“被遮挡”：分屏窗口、部分遮挡、完全遮挡、最小化、其他虚拟桌面、锁屏和托盘隐藏分别属于什么状态？多个应用状态如何附着在同一个时间轴区间上，同时避免把重叠区间相加成虚假的现实总时长？

## Answer

Timelens 不再用“前台”混指两种事实，而采用“显示中”和“聚焦中”。显示中表示应用至少有一个窗口已显示、未最小化、未被系统 cloak、位于当前虚拟桌面且与显示器相交；多个应用可同时显示。聚焦中表示应用拥有 Windows 唯一的 foreground window，并负责接收键盘输入；输入计数只归属聚焦应用。

Timelens 不做像素级遮挡计算，因此部分遮挡和完全遮挡但未最小化的窗口都仍算显示中。最小化、隐藏到通知区域、位于其他虚拟桌面或锁屏期间属于后台；睡眠期间所有应用计时冻结。当前虚拟桌面没有显示中的普通应用窗口时记为桌面空闲，长时间无输入本身不会触发空闲。

时间轴按任何状态变化切成现实时间段。每段只保存一次起止时间，并关联显示中应用集合、唯一聚焦应用、后台应用集合与全局系统状态。应用时长按区间并集计算，同一应用的多个窗口不重复累计；不同应用区间可以重叠，但全局不把各应用时长简单相加为总使用时长。正常会话结束只标记“系统关机或重启”，监控中断和睡眠均不猜测缺失活动。
