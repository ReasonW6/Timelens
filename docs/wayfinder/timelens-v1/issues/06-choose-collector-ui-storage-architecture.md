# 选择采集器、界面与存储架构

Type: grilling
Status: resolved
Blocked by: 02, 03, 04, 05, 14

## Question

在行为语义、Windows 可观测性、权限边界和技术基础事实明确后，选择 Timelens 的进程边界、IPC、事件写入路径、查询投影、SQLite 使用方式、UI 技术与打包形态。决定必须满足资源预算、崩溃隔离、本地优先和无重复 UAC，并记录被拒方案的真实权衡。

## Comments

### 2026-08-22 已确认的共同架构边界

- 提权采集器只负责窗口、输入、会话状态和受限断线缓冲；普通权限主程序负责托盘、最终 SQLite、快照、时间轴、报告、设置与 AI。采集器禁止联网、执行模型输出或打开最终数据库。
- 主程序不可用时，采集器把已聚合事件写入定长追加式缓冲；恢复后按确认号补交。缓冲溢出必须形成监控中断，不得静默伪造完整记录。
- 普通主程序是最终 SQLite WAL 的单写入者；WebP 快照独立存放并由数据库索引。API 密钥进入 Windows Credential Manager，不明文写入 SQLite。
- 两个权限边界通过仅限本机、当前用户与当前会话的 ACL 命名管道通信；消息必须有版本、长度上限与固定类型，禁止任意 SQL、要求访问路径的控制指令、Shell、插件或 AI 内容进入提权采集器。采集器可把自己从已观察窗口解析出的、长度受限的规范化可执行路径作为只读事实发给核心，但该字段不得被解释为命令参数。
- 安装器默认 `Program Files\\Timelens`，并允许用户选择其他本地固定磁盘目录；登录任务、修复与更新跟随实际路径。用户数据库、快照和设置固定在 `LocalAppData\\Timelens`，V1 不跨 Windows 用户共享。
- [构建同功能架构样机并统一测量](14-build-comparable-architecture-spikes.md)已经确定 Rust + windows-rs + Slint 为 V1 基础。

## Answer

V1 安装三个职责固定的程序。普通权限 `Timelens.exe` 是单实例常驻核心、托盘和 Slint UI，也是最终 SQLite WAL 的唯一写入者；快照在受限工作线程执行，AI 以同一普通程序的按需子进程模式执行。最高权限 `Timelens.Collector.exe` 只观察窗口、输入与会话状态，通过 32 MiB 持久校验环形缓冲保存未确认的聚合事件。最高权限 `Timelens.Updater.exe` 只按需应用已验证更新，没有网络或任意执行能力。首次安装注册普通核心登录任务、最高权限采集登录任务和最高权限按需更新任务；异常退出自动重启，用户主动退出则同时停止核心与采集器，重新打开不弹 UAC。

普通核心创建仅限本机、当前用户与当前会话的命名管道，双方核验 Windows 用户、会话、进程路径和正式签名。长度受限、版本化 Protobuf 协议只允许握手、聚合事件批次、连续确认号、心跳及少量固定控制消息；聚合观察可包含采集器从已观察窗口解析出的有长度上限的规范化可执行路径，只作为应用身份事实。协议禁止 SQL、任意文件路径控制指令、Shell、更新参数和 AI 内容，核心也不得把观察路径回送为提权文件操作参数。采集器按序重放未确认事件；缓冲溢出覆盖最旧记录并形成明确监控中断。

SQLite 直接保存活动区间、应用会话、分钟输入桶和系统状态等权威事实，总计与时间轴投影均可重建。核心使用专用异步写入线程、少量只读查询连接、WAL、`synchronous=NORMAL`、约一秒批量提交和每分钟检查点；异常断电后的不确定尾部标为监控中断。Slint UI 只能发出类型化查询，不在 UI 线程执行 SQL，也不启动本机 HTTP 服务。同一 Windows 用户同时只允许一个活动核心和数据库写入者。

正式安装采用 Inno Setup 并允许选择本地固定磁盘路径。普通核心负责下载，离线提权更新器只接受固定暂存目录内通过发布者签名、哈希、版本和安装根校验的非降级包；更新失败自动回滚，不可逆数据库迁移不得静默执行。产品不自动上传遥测，只保留最多 10 MiB、7 天且不含窗口标题、输入内容、快照或密钥的本地诊断日志。

难以逆转的边界记录在[单写入者 Slint 核心 ADR](../../../adr/0002-use-a-single-writer-slint-core.md)与[离线提权更新代理 ADR](../../../adr/0003-use-an-offline-elevated-update-broker.md)。
